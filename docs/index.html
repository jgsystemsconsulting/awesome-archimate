§02 · Specifications and standards

Specifications and standards

  • ArchiMate 3.2 Specification - The Open Group standard defining the ArchiMate 3.2 modeling language, document C226 ArchiMate3 spec (2022)
  • ArchiMate 4 Specification - The Open Group standard defining the ArchiMate 4 modeling language, document C260, published April 2026 ArchiMate4 spec (2026)
  • ArchiMate Model Exchange File Format - The Open Group specification for the XML-based interchange format for ArchiMate models ArchiMate-general spec (2026)
§03 · Certification

Certification

  • ArchiMate Certification - The Open Group certification program for individuals: Foundation and Practitioner levels ArchiMate-general certification (2026)
  • ArchiMate Tool Certification - The Open Group certification program for ArchiMate modeling tools ArchiMate-general certification (2026)
§04 · The Archi tool

The Archi tool

  • Archi - Open-source ArchiMate modeling tool for Windows, macOS, and Linux, with full ArchiMate 3.2 support ArchiMate3 Archi tool (2026)
  • Archi Wiki - Official Archi wiki: user guides, how-tos, and plugin documentation ArchiMate-general Archi docs (2026)
§05 · Plugins and collaboration

Plugins and collaboration

  • Archi plugins - Catalog of official Archi plugins: jArchi scripting, coArchi collaboration, visualization, and more ArchiMate-general Archi plugin (2026)
  • jArchi - Official Archi scripting plugin: automate model queries, reports, and content generation with JavaScript ArchiMate-general Archi plugin (2026)
  • coArchi - Archi plugin adding Git-based model collaboration: shared repositories, commits, and compare ArchiMate-general Archi plugin (2026)
  • coArchi 2 - Second-generation coArchi plugin for Git-based shared model repositories in Archi ArchiMate-general Archi plugin (2026)
§06 · Books

Books

  • Mastering ArchiMate - Gerben Wierda's practitioner book on ArchiMate, Edition 3.2 (PDF released October 2024), with free overview PDFs ArchiMate3 book (2024)
§07 · Example models

Example models

  • ArchiModels - Archived official collection of example ArchiMate models that open in Archi; kept as reference material ArchiMate3 Archi has-model example (2021)
  • ArchiSurance Practice - Community practice models recreating the ArchiSurance case study in Archi ArchiMate3 Archi has-model example (2026)
  • ArchiSurance (archimate-models) - The ArchiSurance example model from the ArchiMate specification, packaged for Archi ArchiMate3 Archi has-model example (2017)

Communities

§10 · Install and usage

Nothing to install

Nothing to install. This list is a curated index: browse it here on GitHub, or clone it:

git clone https://github.com/jgsystemsconsulting/awesome-archimate.git

Open the Contents at the top and jump to a section, or search the page with your browser's find function. Open any entry's link to reach the upstream resource; the list never re-hosts content. To suggest a resource or report a defect, use the Support channels below (or open a pull request that follows CONTRIBUTING.md). See CHANGELOG.md for versions and the release history.
