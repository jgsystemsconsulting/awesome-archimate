Awesome ArchiMate

Curated ArchiMate resources for enterprise architecture and MBSE practitioners. Version 0.1.0.

This is a public-domain (CC0) curated index of Open Group ArchiMate specifications and certification, the Archi tool and its plugins, books, and openable example models. Nothing to install: open the list and follow the links.

First run

  1. Open the full list on GitHub (README with searchable Contents).
  2. Jump to a section that matches your work (specifications, tool, plugins, models).
  3. Suggest a resource or report a dead link via the repository issue forms.
