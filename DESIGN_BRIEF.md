# DESIGN_BRIEF

## Product

Awesome ArchiMate curated index site on GitHub Pages (single long landing with section anchors). Surface type: documentation / technical index. Canonical deep list remains the repository README.

## Audience

Enterprise architecture and MBSE practitioners who already know ArchiMate exists. They bring domain vocabulary (Open Group specs, Archi, TOGAF) and want vetted links fast, not a product pitch.

## Desired impression

credible, precise, quiet, dense-tolerant, navigable

## Primary style

minimal-technical

## Secondary style

none

## Density

high inside sections; generous air between major sections

## Motion level

low

## Visual emphasis

Section index and one primary action (open full list on GitHub / jump to sections). Evidence chips (version, last sweep, entry count) support the claim; they do not compete with the index.

## Avoid

- SaaS feature-card grids and gradient heroes
- Glassmorphism, glow, multi-accent tag carnival
- Indigo/violet defaults and stock people photography
- Centre-everything layouts; Inter/Roboto-only stacks
- CDN-hosted fonts (self-host Plex under docs/fonts/ only)
- Accordion-hiding the list the visitor came for
- Default shadcn gray/violet theme shipped unthemed
- Marketing problem/solution theatre on a curated list
